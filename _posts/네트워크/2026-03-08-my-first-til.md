# 네트워크 일반
----------------
##  1-3 OSI 7계층 모델
`개념 : 서로 다른 시스템간의 효율적인 통신을 위해 정의된 표준`

### 1. 물리계층 (physical Layer, L1)
- 역할 : **비트(0,1)단위 데이터 전송**,상위계층 데이터 전기적,기계적 신호로 변환
- 데이터 단위(PDU) : 비트(bit)
- 프로토콜 : RS-232C,이더넷 물리적부분
- 장비 : 리피트,허브,케이블

### 2. 데이터링크계층 (Data Link Layer, L2)
- 역할 :
  -  논리적 링크 제어 (LLC)
     - 오류제어 , 흐름제어
  - 메체 접근 제어(MAC)
    - 주소 지정(MAC) , 프레임 전송 
- 데이터 단위(PDU) : 프레임(frame)
- 프로토콜 : 이더넷,PPP,ALOHA,LAPB
- 장비 : 스위치,브리지
