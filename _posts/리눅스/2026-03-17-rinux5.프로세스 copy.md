# 프로세스

**메모리에 적재된 실행상태의 프로그램을 프로세스라고 한다.**

**프로세스의 5가지 상태**
- 생성
- 실행
- 준비
- 대기
- 종료

## PID 와 PPID

**PID 현재 프로세스를 의미하고**
**PPID 는 부모 프로세스를 의미한다.**

리눅스는 프로세스를 생성할때 **fork()**를 사용해 새 프로세스를 생성한다.

**fork()** 로 생성할경우 원본 프로세스는 **부모 프로세스** 가 되고, 생성되는 프로세스는 **자식 프로세스** 가 된다.

**고아프로세스**: 자식 프로세스보다 부모 프로세스가 먼저 종료된 경우 자식 프로세스를 고아 프로세스라고 부른다.

**좀비프로세스**: 자식 프로세스의 일이 끝났는데 부모 프로세스가 종료를 안시켜주고 남아있는 프로세스 상태를 좀비 프로세스라고 부른다.

## ps (프로세스 명령어)
- ps - e(전체 프로세스를 보여줌)
- ps - f(정보 출력시 full format을 사용함)
  - ps -f 가족관계 파악 
- ps - l(정보 출력시 long format을 사용함)
  - ps -l 은 건강상태 파악

job 은 백그라운드 작업목록만ㅁ
fg 는 명령어를 실행할수없고
bg 는 명령어를 실행할수있음
nice 는 프로세스에게 cpu 우선순위를 주는것 -20~19 까지있는데 숫자가 클수록 우선순위는 낮음 아주 나이스한애들
